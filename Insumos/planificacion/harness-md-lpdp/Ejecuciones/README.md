# Ejecuciones

El Agente Orquestador deja aqui un registro breve por trabajo significativo. Nombre sugerido: `AAAA-MM-DD-agente-tema.md`. Al reanudar el mismo trabajo, actualiza su archivo.

```md
# Agente — tarea

| Objeto | Última etapa comprobada en este registro | Fecha del asiento | Evidencia |
|---|---|---|---|
| Fuente y versión o Dominio | Etapa, o `No acreditada` | Fecha real | Enlace al producto comprobado y referencia al asiento técnico de etapa |

- Qué hizo:
- Decisiones operativas y motivo:
- Resultados: rutas o enlaces.
- Pendientes y siguiente paso:
```

Una decisión humana se menciona sólo si consta. Este registro sirve para ubicar y retomar resultados, sin duplicar su contenido.
La tabla se usa solo si el trabajo trata una Fuente o un Dominio. Resume el
último asiento comprobado de este archivo; para conocer la etapa vigente hay
que revisar si existe un asiento técnico posterior en otro registro y comprobar
su evidencia. El estado de ejecución no reemplaza la etapa del ciclo.
