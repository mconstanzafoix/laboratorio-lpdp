# Art. primero, num. 5, subnum. tres, lit. m

- **Contexto:** véase el árbol de esta Fuente.

## Texto literal (bloque espejo)

> m) Base de datos personales: conjunto organizado de datos personales, cualquiera sea la finalidad, forma o modalidad de su creación, almacenamiento, organización y acceso, que permita relacionar los datos entre sí, así como realizar su tratamiento.

## Análisis breve
Define la base de datos como un conjunto organizado que permite relacionar y tratar datos personales. La finalidad, el formato y la modalidad de creación, almacenamiento, organización o acceso no limitan el concepto.
