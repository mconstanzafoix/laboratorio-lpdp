# Art. primero, num. 8, art. 16 reproducido de Ley 19.628, inc. 3

- **Contexto:** [artículo del nivel inmediato](articulo.md); [instrucción modificatoria](../instruccion.md).

## Texto literal (bloque espejo)

> Las excepciones para tratar datos sin consentimiento, mencionadas en este artículo, se entienden aplicables al tratamiento de datos que no revisten el carácter de datos sensibles.

## Análisis breve
Extiende las excepciones sin consentimiento del artículo también a datos que no son sensibles. La extensión evita interpretar que las causales sólo sirven para la categoría especial.
