# Art. primero, num. 7, art. 8 reproducido de Ley 19.628, lit. c

- **Contexto:** [artículo del nivel inmediato](articulo.md); [instrucción modificatoria](../instruccion.md).

## Texto literal (bloque espejo)

> c) Si el tratamiento se realiza respecto de datos obtenidos de una fuente de acceso público y no existe otro fundamento legal para su tratamiento.

## Análisis breve
Permite oponerse al tratamiento de datos provenientes de una fuente pública si no existe otra base legal. El origen público no cancela la oposición, pero una base independiente puede impedir esta causal.
