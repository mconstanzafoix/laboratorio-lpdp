# Art. primero, num. 12, art. 25 reproducido de Ley 19.628, inc. 3, frag. 1

- **Contexto:** [unidad madre](inciso-03.md); [fragmento siguiente](inciso-03-fragmento-02.md).

## Texto literal (bloque espejo)

> No podrán comunicarse o hacerse públicos los datos personales relativos a la comisión y condena de infracciones penales, civiles, administrativas o disciplinarias, una vez prescrita la acción penal, civil, administrativa o disciplinaria respectiva, o una vez que se haya cumplido o prescrito la pena o la sanción impuesta,

## Análisis breve

Prohíbe comunicar o publicar datos de infracciones cuando se extingue la acción o se cumple o prescribe la sanción.

## Tipo de norma

Regulativa: la fórmula expresa «No podrá» regula una conducta o una facultad ejercible. Prohíbe comunicar o publicar datos de infracciones cuando se extingue la acción o se cumple o prescribe la sanción.
