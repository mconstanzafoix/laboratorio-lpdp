# Art. 13, inc. 1, lit. c

## Texto literal (bloque espejo)

> c) Cuando el tratamiento de datos sea necesario para la celebración o ejecución de un contrato entre el titular y el responsable, o para la ejecución de medidas precontractuales adoptadas a solicitud del titular.

## Análisis breve

La celebración o ejecución de un contrato entre titular y responsable, o medidas precontractuales pedidas por el titular, habilitan tratamiento necesario para esos fines. La necesidad y el vínculo con ese contrato o solicitud limitan esta base.
